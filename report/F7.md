# F7 — References

**Written 2026-08-10. Sole writer of this file.** Sections F1–F6 are elsewhere and are not
edited by this file.

Discharges requirement **F7**, *"References."* One list, one format, built from the works
F1–F6 actually cite.

## How this list was built

Every entry below was harvested by reading `report/F1-F3.md`, `report/F4.md`,
`report/F5.md` and `report/F6.md` in full and by a name-level scan of the same four files
(`grep -niE` over the set of named works, model names, author surnames and identifier
patterns `arXiv`/`doi`/`[n]`/`(Author, year)`). **The report uses no numbered or
author–year citation markers of its own** — works are named inline in prose and in tables —
so enumeration is by name, not by marker. Nothing is listed here that is not cited in
F1–F6; a work the pre-registration anticipated but the report does not cite is recorded in
§F7.2 rather than given an entry.

## Provenance markers — one per entry, no entry without one

| Marker | Meaning |
|---|---|
| **`[repo]`** | Read from a file in this project. The path is given. |
| **`[paper-bib]`** | Taken from the bibliography of `files/project/TQnet.pdf`. The printed page is given. |
| **`[standard]`** | A standard citation supplied without a copy in this project to check it against. |

**Two notes on the markers, both forced by what the files say rather than by preference.**

1. **`TQnet.pdf`'s bibliography is author–year and alphabetical; it prints no reference
   numbers.** No `[paper-bib]` entry can therefore carry a reference number. Each carries
   instead the page its entry is printed on, which is the strongest locator the document
   offers. The printed page number and the PDF page number coincide throughout that
   document's bibliography (the footer of PDF page 10 reads `10`), so a single page number
   is unambiguous under D17's spirit.
2. **`[repo]` is used only for files opened while writing this list.** Every path below
   was read.

## F7.3 Two entries that could not be sourced where this job expected

Recorded here rather than resolved, because resolving them would mean inventing a locator.

**Dish-TS (entry 2) and SAN (entry 11) are not cited by TQNet.** This job's instructions
state that CycleNet, Non-stationary Transformers, Dish-TS, SAN and the ETT/Informer paper
"are all cited by TQNet itself" and should be marked `[paper-bib]` with a printed reference
number. Three of those five are: CycleNet (p. 11), Non-stationary Transformers (p. 11) and
Informer (p. 12), and they are marked accordingly. **Dish-TS and SAN are not.** Searched
over the full extracted text of `files/project/TQnet.pdf`, the string `Dish` occurs zero
times, and `SAN` as a standalone token, "slice adaptive" and "adaptive normalization" occur
zero times. (The nearest neighbours in that bibliography are Ye et al., *Frequency adaptive
normalization for non-stationary time series forecasting*, NeurIPS 2024, and Kim et al.'s
RevIN — neither is the work F4 §4.3 names.) Both are therefore `[standard]`, which is the
outcome the instructions' own fallback rule prescribes for a work with no copy to check
against.

**No `[paper-bib]` entry can carry a reference number**, for the reason given at the head of
this file: `TQnet.pdf`'s bibliography is alphabetical author–year and prints none. Printed
page numbers are given instead, and they coincide with the PDF page numbers.
